## Installing 💻

-  Go to `View -> Command Palette` or type `Ctrl+Shift+P`/`cmd+Shift+P`
-  Then enter `Install Extension`
-  Write `Wayne`
-  Select it or press Enter to install
-  Enjoy 🎉

## Activating theme ⚡️

Run Visual Studio Code. The Wayne Theme will be available from File -> Preferences -> Color Theme dropdown menu.
